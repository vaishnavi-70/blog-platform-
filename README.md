# Blog Platform with Comments

A lightweight full-stack blogging platform where users can create, read, update, delete posts, and interact through a dynamic comment section. Built using **Node.js**, **Express**, and **Vanilla JavaScript** with in-memory data management for smooth local testing and development.

## 🚀 Features
* User registration, login, and authentication interface.
* Create, edit, and delete blog posts seamlessly.
* Interactive comment section for user engagement and discussion.
* Backend powered by RESTful APIs and clean database/data integration.

## 🛠️ Tech Stack
* **Backend:** Node.js, Express.js, CORS
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Storage:** In-Memory Array / Local Storage
